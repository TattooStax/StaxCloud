# Final Traditional Tile Set — Sheet A + B's contacts & bubble

Owner's pick (2026-11-02): Sheet A, with Sheet B's contacts and bubble swapped in.
All tiles are 512×512 PNG, emblem centered at a uniform scale (max dimension 468px),
background = the sheet's near-black (26,23,20). Nothing is wired into the app yet.

## 48px legibility verdicts (from contact-sheet-48.png, inspected at true 48px)

- **reaper** — Instant. Skull, dusty-pink hood, teal blade all survive.
- **magnet** — Instant. Horseshoe form + gold/teal split; the tiny +/− tip marks vanish, not needed.
- **stamp** — Instant. Knob handle and base read cleanly.
- **bubble** — Reads as a speech bubble: teal balloon + pointed tail carry it; the cream band can momentarily read as a strap, but the balloon/tail read wins.
- **envelope** — Instant. Pink flap sells it.
- **clipboard** — Instant. Clip, board, and rule lines all survive.
- **book** — Instant. Open-book silhouette with teal spine.
- **contacts** — Instant, the strongest small-size read of the set. Two profile busts, zero interior detail.
- **machine** — **Weakest tile — flagged.** A's gold coil machine is the richest drawing on the sheet; at 48px the coil/screw detail merges. It still reads as a tattoo machine from the diagonal profile, pink grip, and needle point, but it leans on context more than the other eleven. One simplify fix was attempted (bold few-shape redraw) and re-checked at 48px: the redraw read *worse* — an abstract block stack with muddled anatomy — so A's original cut was kept. If any tile gets a future redraw, it's this one, ideally as a bold *profile* silhouette.
- **frame-rose** — Instant. Gold frame + rose.
- **toolbox** — Instant. Pink box, handle, clasp.
- **links** — Instant. Two interlocked links, gold/teal.

## Overall

11 of 12 read instantly at 48px; machine is serviceable but is the set's known soft spot.
Palette discipline holds across all 12 (teal / dusty pink-red / mustard gold / cream on
near-black, no text anywhere) — B's chain-link gradient slip did not carry over, since
only A's links were used.
